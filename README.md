# BioDataLab

BioDataLab is an open-source Python toolkit for biological,
agricultural and scientific data analysis.

## Features

- Load datasets from CSV and Excel files.
- Clean missing values and duplicate records.
- Detect statistical outliers using the IQR method.
- Calculate descriptive statistics.
- Analyze correlations between numerical variables.
- Generate reproducible data analysis workflows.
